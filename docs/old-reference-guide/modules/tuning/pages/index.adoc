= Tuning
:page-aliases: README.adoc

Sophon provides capabilities to tune the performance of your Sophon applications.
This includes capabilities to take event snapshots, segment tuning, command processing, and general RDBMS tuning suggestions.
This section of the documentation intends to detail the capabilities that Sophon provides to help tune your Sophon applications.

A summary of the various subsections is given below:

[cols="<,<"]
|===
|Sub-Section |Purpose

|xref:event-snapshots.adoc[Event Snapshots] |Sophon provided capabilities to create event snapshots for optimizing Aggregate loading
|xref:event-processing.adoc[Event Processing] |Sophon provided capabilities for tuning batching and parallel processing of events
|xref:command-processing.adoc[Command Processing] |Sophon provided capabilities for Command message processing
|xref:rdbms-tuning.adoc[Relational Database Tuning] |Tuning suggestions when using Sophon together with a Relation Database
|===
